# v4.81a-dev.85928f9-chriz.1

This release adds optional dialogue while shapeshifted and adopts upstream-based
fork numbering. CEBG manages its artifact pin separately; this owner release does
not update the collection recipe or any installed game.

## Version migration and upstream base

This release moves from independent **`chriz-v1.6.0`** numbering to
**`v4.81a-dev.85928f9-chriz.1`**: upstream base followed by our patch revision.
All three main TP2 VERSION fields use the full new identity. Earlier published
tags, assets, historical notes and installed version labels are unchanged.
The new suffix starts this naming scheme and retains all prior fork changes.

Upstream supplies no TP2 VERSION or newer development label for these post-tag
commits. The September 29 review found no incoming upstream commits to merge;
the included upstream base is the same as in the legacy 1.6.0 release.
Future upstream-only updates may keep our revision suffix when our patch layer
is unchanged. Our patch changes advance it. See [versioning](../fork-versioning.md).

## Changes

- Optional tweak **51010**, **Allow talking in Shapeshifter and Hivemaster
  forms**, removes the form items' Talk restriction for the selected installed
  kits. It is a separate opt-in choice and adds no EEex dependency.
- Transformation behavior, combat stats, Natural Spell progression and other
  action restrictions remain as before. Genuine Silence is unaffected.
- The version helper synchronizes all three main installers and checks their
  agreement with the intended release identity.

The existing Archer and other released balance changes are retained. Fighter
specialization remains a discussion item; Mystic Fire and other unspecified
kit changes are outside this release.

## Validation and installation boundary

September 29 results: all 12 focused checks passed: seven offline version tests
and five synthetic WeiDU shifted-dialogue tests. The latter cover selecting
either/both/neither kit, unrelated restrictions and item data, missing or already
unrestricted forms, reinstall and byte-exact uninstall restoration. All three
installer versions matched the release identity, and Git accepted its tag syntax.

The existing shifted-dialogue implementation and tests, historical release notes
and legacy 1.6.0 tag were preserved unchanged. The deferred Mystic Fire plan was
left outside the release commit. The [scope and acceptance notes](../plans/2026-09-27-shifted-dialogue.md)
remain applicable. Christopher approved this owner release for the combined CEBG
test package without an additional standalone manual playtest. No live game or
save was changed, and these focused results do not claim live-engine acceptance.

Install component 51010 after the chosen Shapeshifter/Hivemaster kits and other
mods that change their forms. Updating source files alone does not update an
installed game. An already active form may need to return to natural form and
transform again after a planned update. No save repair or CEBG hotpatch is
included. Existing Spell Revisions exclusions in the README still apply.
