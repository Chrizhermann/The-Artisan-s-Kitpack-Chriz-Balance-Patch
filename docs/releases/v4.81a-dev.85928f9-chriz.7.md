# v4.81a-dev.85928f9-chriz.7

Recurring kit auras and Tracking could keep saving or resting unavailable
because their projectiles counted as active combat effects. This release gives
those passive effects their own save-compatible delivery. It is a bug fix for
the frozen Chriz fork.

## Changes

- Combat Casting and Eldritch Knight Awareness use save-compatible projectiles.
  The shared Combat Casting installer refreshes its projectile and dispatcher in
  either install order with Bardic Wonders.
- The shared ally and enemy pulses used by the Paladin, Cavalier, Inquisitor,
  Undead Hunter, Blackguard, Martyr, Beast Master, Totemic Druid and Red Wizard
  Edwin get canonical projectile copies even if WeiDU already registered their
  IDs.
- Dedicated profiles cover conditional and recurring effects for Cavalier,
  Hivemaster, Kensai, Pale Master and Shapeshifter. Totemic Guardian and the
  Samurai's repeating Bushido proximity check also use save-compatible
  projectiles. The existing pulse geometry and target filters are preserved.
- Tracking rebuilds its 800-, 1,200- and 1,600-unit pulses even when another
  component initialized Tracking first. The legacy Stalker delivery uses a
  dedicated 2,000-unit projectile. Tracking still reveals creatures, and the
  engine's separate visible-hostile save and rest refusal can still apply.
  Active combat effects retain their regular save behavior.

## Verification

- 154 offline and WeiDU regression tests passed. WeiDU 24900 parsed all three
  versioned TP2s.
- Synthetic BG2:EE and EET installer checks exercised the projectile fixes.
  The We Overwrite mutation fixtures seeded changed projectiles and spell
  headers, verified the intended installed bytes and local projectile IDs,
  and checked byte-exact restoration on uninstall for the covered resources.
- Live in-game save and rest behavior is pending a playtest. Players receive
  these changes when installing the affected components from this release.
